## 어려웠던 점 3가지와 해결
1. 화면 폭에 따라 카드 수를 바꾸는 것이 어려웠다. 기본은 1열, 600px 이상은 2열, 1024px 이상은 4열로 미디어 쿼리를 적용했다.
2. 포스터가 없는 영화의 화면 처리가 어려웠다. 대체 표지에 첫 글자를 표시하고 CSS 그라데이션을 적용했다.
3. 상세 페이지에서 포스터와 정보를 나란히 배치하는 것이 어려웠다. CSS Grid를 이용해 큰 화면에서는 1:2 비율로 배치하고 작은 화면에서는 한 열로 보이게 했다.
